# v7 — 50-Prompt Choreography
Rule, set by Oliver 2026-10-26: every concept gets a witty image + a witty animation. No viewport is static for more than 5 seconds.
How that rule is met here: 50 segments, 7.04s each = 351.9s total (the full VO2). Inside every segment the camera is ALWAYS moving (slow zoom in 1.00 -> 1.12, or slow pan), a headline text-reveals at 0.0-0.5s, a highlight sweep lands at ~2s, and a micro-interaction fires at ~4s (pill slides, icon pulses, card tilts, stamp lands, highlight moves). So the longest gap with no change is under 5s — in practice under 2s.
Text system, borrowed from effective AI-niche Shorts/Longs (AI Frontier, Fireship-style test beats, CapCut faceless templates): one large headline per claim, pill label top-left, white-on-black-bar sentence caption underneath (karaoke in v7: words turn gold as spoken), highlight = gold bar behind the key word, zoom-in on the highlighted word like a movie punch-in at ~2s. All on-screen text is added in ffmpeg/PIL AFTER generation — never rely on a generated clip to spell a model name or a number.
Labels: every generated video/image is bannered "AI CLIP / AI IMAGE — METAPHOR ONLY, NOT EVIDENCE". Proof segments are bannered "RENDERED FROM LIVE PAGE VISIT — NOT A LIVE SCREENSHOT". No generated visual is presented as a run, a screenshot, or a product.
