Second, REA. And this is the trick inside the trick: REA is not a model, and it is not a Claude product at all. REA stands for Reverse Engineer Anything. It is a GitHub repo, github.com/morluto/rea, a free, open-source tool that lets a coding agent use reverse-engineering tools to inspect software you own or are allowed to examine — binaries, apps, websites — and explain how it works, down to the code underneath. It plugs into agents like Claude Code, Codex, and Cursor through an MCP server, and the analysis runs locally. It went viral in mid-October, and that virality is exactly why it got pasted into a model-news title. It was never banned by Anthropic, because Anthropic does not own it, and it is not a model to ban.
