## Long expansion (6-8 minutes) — from iAsk's written answer structure
The written answer's five contrasts become five evidence beats. Each beat is 60-120 seconds, one headline per claim, no viewport static over 5 seconds.

1. **Hook (0-30s)** — "Anthropic just dropped Claude Duet — here is what it actually changes, and what it does not." Visual: your own desk/workspace image, slow zoom, pill label "Claude Duet".
2. **Execution environment** — Code runs on your local machine through a terminal; Duet is described as cloud-based and persistent. Visual: terminal window vs a cloud workspace card, side by side. Proof card: primary Anthropic wording for where each one runs, once verified.
3. **Persistence and memory** — Code sessions are described as stateless; Duet as always-on with persistent memory. Visual: a session that resets vs a ledger that keeps growing. Micro-animation at each comma/idea shift: the ledger adds a line.
4. **Collaboration** — Code is single-user; Duet is described as team-shared sessions and artifacts. Visual: one chair vs a shared table with multiple cursors. Highlight sweep as each collaborator is named.
5. **Scope** — Code is code-focused; Duet is described as covering wider work such as email triage, research, and scheduling. Visual: a code editor shrinking into a wider dashboard of tasks. One witty image per task, not a text list.
6. **Integrations** — Code needs manual setup; Duet is described as having thousands of managed integrations. Visual: plugs being connected one by one. Do not put a specific integration count on screen unless a primary source confirms it — iAsk's count is unverified here.
7. **Verdict / checklist close (animated, never a static slide)** — iAsk's conclusion, labelled as such until verified: choose Code for solo terminal work, Duet for teams needing shared context and persistent memory. Checklist items build in one by one with a moving highlight, ending on: "Pick the workflow, not the logo."
